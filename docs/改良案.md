C:\install\PC\windows設定\AutoHotkey の
「IME入力モード表示.ahk」を、入力遅延を発生させにくい構成へ改良してください。

目的:
- BraveのAmazon・ChatGPT、CodexアプリなどのChromium系入力欄で、日本語変換確定後に文字入力が滞留し、後から高速に流れ込む現象を防ぐ。
- サクラエディタを含む既存アプリで、IME入力モード表示の見た目・位置・色・変換中の表示挙動を維持する。
- 長時間動作しても、UIA参照、タイマー、配列、Map、ログ、イベントが無制限に蓄積しないようにする。

現在判明している問題候補:
1. InitializeImeKeyTracking()のInputHookが全キーを監視し、文字キーごとにIME_GET()とIME_GetConvMode()を同期実行している。
2. インジケーター表示中は75～100ms周期で監視し、1サイクル中にIME_GET()、IME_GetConvMode()、IME_GetConverting()を重複して呼んでいる。
3. lib\IMEv2.ahkの_IME_SendMessage()は、タイムアウトなしのSendMessageを使用している。
4. DetectInputContext()のChromium判定がchrome.exeとmsedge.exeだけで、brave.exeとCodexのUIプロセスであるChatGPT.exeを判定できていない。
5. Chromium系入力欄でネイティブキャレット取得に失敗した際、UI Automationの親要素探索を最大6段行う可能性がある。
6. UIAv2.ahkには処理済みHWNDを保持するactivatedHwnds Mapがある。主原因とは断定しないが、無効なHWNDが残り続けないか確認する。
7. 再起動で改善することがあるため、UIAのCOM参照、入力フック、同期呼び出し、イベント処理の一時的な滞留も調べる。

実装方針:
- InputHookのOnKeyDown内では、IME・UIA・ウィンドウへの同期問い合わせを行わないこと。
- キーコールバックでは「入力が発生した時刻の更新」と、必要なら一発タイマーによる監視要求だけを行うこと。
- IME状態は1監視サイクルにつき一度だけ取得し、スナップショットとして各判定処理で共有すること。
- 同じサイクル内でIME_GET()やIME_GetConvMode()を重複実行しないこと。
- タイムアウトなしのSendMessageをホットパスからなくすこと。
- 必要なら_IME_SendMessage()に後方互換性を保ったタイムアウト指定を追加するか、このスクリプト専用の安全な問い合わせ関数を用意すること。
- タイムアウト時は処理を待ち続けず、直前の正常なIME状態を短時間だけ使用するか、インジケーターを安全に非表示にすること。
- UIAまたはIME問い合わせが一定時間以上かかった場合、同じ重い処理を短時間繰り返さないサーキットブレーカーを設けること。
- Chromium判定はプロセス名の列挙だけに依存せず、ウィンドウクラスやChrome_RenderWidgetHostHWNDの存在も利用して判定すること。
- 少なくともchrome.exe、msedge.exe、brave.exe、ChatGPT.exeを正しく扱うこと。
- Chromiumでは不要な親要素探索を行わないこと。
- ネイティブキャレット、MSAA、UIAの順序を再検討し、UIAは本当に必要な場合だけ呼ぶこと。
- UIA要素を監視サイクルを越えて不必要に保持しないこと。
- Mapや配列を追加する場合は、上限、期限、無効HWNDの削除処理を設けること。
- 現在の一発タイマー方式と多重実行防止は維持し、タイマー呼び出しがキューに蓄積しないようにすること。
- 既存の診断ホットキー、色、オフセット、コメント、表示仕様を維持すること。
- lib\UIAv2.ahkは影響範囲が大きいので、必要性が実証できない限り変更しないこと。
- lib\IMEv2.ahkを変更する場合は、既存利用箇所との後方互換性を確認すること。

性能診断も追加してください:
- 既定では無効にする。
- 監視サイクル全体、ResolveAnchor、UIA取得、IME取得の各処理時間を計測する。
- 20msまたは妥当と判断した閾値を超えた処理だけをTSVへ記録する。
- 時刻、対象プロセス、HWND、処理名、所要時間、キャレット取得元、タイムアウト有無を記録する。
- 正常なサイクルを毎回記録しないこと。
- ログはサイズ上限またはローテーションを設け、無制限に増加させないこと。
- 診断処理自体が入力遅延を増やさないようにすること。
